# কিংকর্তব্যবিমূঢ় — login soho website

## Chalanor niyom
1. Node.js 22.13 ba tar upore install thakte hobe (node -v diye dekhun)
2. Terminal e ei folder e ashun:  cd kinkortobyobimur
3. Chalan:  node server.js
4. Browser e kholen:  http://localhost:3000

Kono npm install lagbe na.

## Folder
server.js          -> backend (login, logout, data save)
data/app.db        -> database (auto toiri hoy)
public/login.html  -> login / notun account page
public/css/auth.css, public/js/auth.js -> login page er design o code
public/app.html    -> apnar main app (login chhara khola jay na)
